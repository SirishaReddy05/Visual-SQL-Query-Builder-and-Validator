# Visual-SQL-Query-Builder-and-Validator


QueryCraft is an interactive, educational web application designed to bridge the gap between writing SQL queries and understanding how they are processed under the hood. It features a visual query builder and a custom-built, real-time SQL parser that demonstrates core compiler design concepts.

🚀 Features

Visual Query Builder: Construct SQL queries intuitively using dropdowns, checkboxes, and input fields for tables, columns, WHERE conditions, ORDER BY clauses, and LIMITs.

Direct SQL Input: A built-in code editor for users who prefer to type raw SQL manually.

Custom Lexical Analyzer (Tokenizer): Breaks down the raw SQL string into a sequence of meaningful tokens (Keywords, Identifiers, Strings, Numbers, Operators).

Recursive Descent Parser: Validates the tokens against supported SQL grammar rules and constructs an Abstract Syntax Tree (AST).

Interactive Parse Tree: Utilizes D3.js to render a beautiful, interactive, draggable, and zoomable visual representation of the AST.

Live Diagnostics: Provides instant, real-time feedback on lexical and syntax errors, highlighting exactly where the query fails.

🛠️ Tech Stack

Frontend: HTML5, Vanilla JavaScript, CSS3

Styling: Tailwind CSS (via CDN)

Data Visualization: D3.js (v7) for rendering the Parse Tree

Architecture: Zero-build-step, single-file application for maximum portability.

📚 Compiler Design Concepts Demonstrated

This project serves as a sandbox for understanding front-end compiler phases:

Lexical Analysis: The Lexer class scans the input character by character, ignoring whitespace and grouping characters into valid SQL tokens.

Syntax Analysis (Parsing): The Parser class consumes the tokens generated by the lexer, enforcing SQL grammar rules (e.g., ensuring FROM follows SELECT) using the Recursive Descent parsing technique.

Abstract Syntax Tree (AST) Generation: The parser outputs a hierarchical JSON object representing the logical structure of the query, stripping away unnecessary punctuation.

Error Handling: The application intercepts and gracefully displays both Lexical errors (e.g., unterminated strings) and Syntax errors (e.g., missing keywords or unexpected tokens).
